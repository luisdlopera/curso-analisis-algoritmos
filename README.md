# Análisis y Diseño de Algoritmos

Repositorio central del curso **Análisis y Diseño de Algoritmos**. Este espacio contiene el código fuente, pruebas empíricas, mediciones de rendimiento y los cinco informes de laboratorio desarrollados a lo largo del semestre académico.

## Estructura del Repositorio

El proyecto organiza el material de trabajo en tres módulos principales:

* `laboratorios/`: Almacena las entregas formales y reportes de los cinco laboratorios evaluativos del curso, incluyendo su código y documentación técnica.
* `ejercicios-clase/`: Contiene los ejercicios prácticos no evaluativos resueltos durante las sesiones de clase presenciales y sincrónicas.
* `benchmarks/`: Scripts compartidos para la medición empírica de tiempos de ejecución, perfiles de memoria y generación de gráficas de complejidad asintótica.

## Guía de Uso y Ejecución

Para clonar y explorar los recursos de este repositorio en un entorno local:

```bash
# Clonar el repositorio
git clone https://github.com/luisdlopera/curso-analisis-algoritmos.git
cd curso-analisis-algoritmos

# Configurar entorno virtual en Python
python3 -m venv .venv
source .venv/bin/activate

# Verificar versión de Python
python3 --version
```
